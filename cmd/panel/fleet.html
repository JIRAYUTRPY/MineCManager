เครื่อง VM

เพิ่ม / เปลี่ยนข้อมูล VM

เทียบ fingerprint กับ console ของผู้ให้บริการ VM ก่อนบันทึก: ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256

VM ต้องมี Python 3 และ user ต้องเป็น root หรือมี sudo บนเครื่องนั้น Credentials จะถูกเข้ารหัสก่อนบันทึก

ติดตั้ง Minecraft

ติดตั้งใน /srv/minecmanager/<server-id> • เลือก Java อัตโนมัติ • ไม่เขียนทับ server เดิม

หลังติดตั้งตรวจ logs ว่ามี “Done” แล้วเปิด TCP game port ใน firewall ของ VM/Cloud ก่อนเชื่อมต่อ

Files / OS administrator

สิทธิ์ส่วนนี้ควบคุมเครื่องระดับ root รวมถึงไฟล์ระบบและ services ใช้เฉพาะผู้ดูแล infrastructure

Editor ตรวจ SHA-256 ป้องกันเขียนทับไฟล์ที่เปลี่ยนไปแล้ว การบันทึกไฟล์ระบบไม่ได้ตรวจ syntax หรือ restart service ให้อัตโนมัติ

OS command console

ใช้จัดการ packages, processes, firewall, permissions และงานไฟล์อื่น ๆ คำสั่งทำงานแบบ non-interactive จำกัด 120 วินาที ระวังการปิด SSH หรือเครือข่ายที่ Panel ใช้อยู่

Cloudflare DNS / R2

ตั้งค่าการเชื่อมต่อ

ใช้ DNS token ที่มี Zone Read / DNS Edit และ R2 credentials ของ bucket สำหรับ Object Read & Write เว้นช่อง secret ว่างเพื่อใช้ค่าเดิม

Minecraft ใช้ DNS only การสร้าง DNS ไม่ได้เปิด port, ติดตั้ง TLS หรือ proxy TCP ของเกม

Backup / Restore

ใช้ Server ID ด้านบน การสำรองจะหยุด server ชั่วคราว แล้วเริ่มกลับหากเดิมเปิดอยู่

เวลา schedule เป็น UTC และต้องเปิด Panel ไว้ R2 retention ให้กำหนด bucket lifecycle บน Cloudflare; จำนวนชุดด้านบนใช้กับ VM เท่านั้น

ต้องหยุด server ก่อน ระบบตรวจ checksum และเก็บ root เดิมไว้ย้อนกลับ
